
# 📘 Assignment: Games in Python

## 🎯 Objective

Build a Hangman-style word guessing game in Python to practice strings, loops, conditionals, and user input.

## 📝 Tasks

### 🛠️ Build the Hangman Game

#### Description
Create a Python program that selects a random word from a predefined list and lets the player guess letters until they win or run out of attempts.

#### Requirements
Completed program should:

- Randomly select a secret word from a predefined list of words.
- Accept single letter guesses and track letters already guessed.
- Display current progress with blanks and revealed letters, like `_ a _ g _ a _`.
- Track remaining incorrect attempts and stop the game when attempts reach zero.
- Show a win message when the word is fully guessed and a lose message if the player runs out of attempts.

### 🛠️ Improve the Game Experience

#### Description
Add validation and a replay option so the game is more user-friendly and robust.

#### Requirements
Completed program should:

- Reject invalid input such as empty entries, non-letter guesses, and repeated letters.
- Display the letters that have already been guessed.
- Ask the player if they want to play again after the game ends.
- Keep the game logic clear and easy to follow.
